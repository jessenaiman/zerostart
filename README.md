# ZeroStart: One-Command Python Project Initialization

ZeroStart is a professional Python project template designed for simplicity and extensibility, using standard `pip` within a virtual environment. It provides a modular setup with scripts for installing dependencies, setting up documentation, and ensuring code quality.

## Features

- Modular dependency installation with `pip`.
- Comprehensive Sphinx documentation setup.
- High-end testing, linting, and static typing tools.
- Terminal UI for clear feedback.
- GitHub-ready configuration.

## Quick Start

1. Clone this repository:

   ```bash
   git clone <repository-url>
   cd zerostart
   ```

2. Create and activate a virtual environment:

   ```bash
   python3.13.2 -m venv .venv
   source .venv/bin/activate  # Linux/MacOS
   # or .venv\Scripts\activate (Windows)
   ```

3. Run the initialization script:

   ```bash
   bash scripts/zerostart.sh
   ```

## Scripts

- `zerostart.sh`: Main script to initialize the project and call all others.
- `install_python.sh`: Verifies Python 3.13.2 installation.
- `install_main.sh`: Installs core application dependencies (e.g., pydantic, ruff).
- `install_test.sh`: Sets up testing tools (e.g., pytest, mypy).
- `install_documentation.sh`: Configures Sphinx documentation.
- `install_game.sh`: Adds game development libraries (e.g., arcade).
- `install_database.sh`: Installs database tools (e.g., SQLAlchemy).
- `install_security.sh`: Sets up security linting (e.g., bandit).
- `install_math.sh`: Adds math/physics libraries (e.g., numpy).

## Pushing to GitHub

To share your project on GitHub:

1. Initialize a git repository: `git init`
2. Add files: `git add .`
3. Commit changes: `git commit -m "Initial commit"`
4. Create a GitHub repository and push:

   ```bash
   git remote add origin <repository-url>
   git branch -M main
   git push -u origin main
   ```

5. Verify CI/CD in the GitHub Actions tab.

## Configuration Files

Check these files for customization:

- `pytest.ini`: Testing setup (coverage, verbosity).
- `mypy.ini`: Static typing rules.
- `ruff.toml`: Linting and formatting.
- `.pre-commit-config.yaml`: Pre-commit hooks.
- `.github/workflows/ci.yml`: CI/CD pipeline.
Working versions are included; adjust as needed.
